# GreenUp-frontend

Front-End do Projeto Integrador GreenUp, implementada com React 18, Vite 6, React Router 7, Tailwind 4, Recharts, Sonner (toasts), MUI/Radix.

## Execução local para desenvolvimento

1. `npm i` - Instalar as dependências
2. `npm run dev` - Iniciar a aplicação

- O front abre em http://localhost:5173
